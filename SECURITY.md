# Security policy

These contracts handle real payments, so we take reports seriously.

## Reporting a vulnerability

- Use **GitHub private vulnerability reporting**: the "Security" tab of this repository → "Report a vulnerability".
- Or send a direct message to [@bytejury](https://x.com/bytejury) on X and we will move to a private channel.
- Please do **not** open a public issue or post details publicly until a fix is deployed.

Include the contract and function, the impact, and a proof of concept (a Foundry test is ideal).

## Scope

The contracts in `src/` as deployed on Robinhood Chain (addresses in the README). The website and the scanner are
out of scope for this repository.
